# HearWave: bản cài đặt

Repo này chỉ chứa bản cài đặt của app HearWave (trước đây là liveTranscript), không có mã nguồn.

- **Cài lần đầu**: vào mục [Releases](../../releases/latest), tải file `.dmg` (macOS, Apple Silicon), `.exe` (Windows) hoặc `.deb` (Ubuntu).
- **Cập nhật**: app đã cài tự kiểm tra khi mở; có bản mới thì app hỏi, bấm **Tải và cài đặt**.
- **Kích hoạt**: app cần mã kích hoạt do người phát hành cấp.

Hai file "Source code (zip / tar.gz)" GitHub tự gắn vào mỗi bản phát hành chỉ chứa README này.
